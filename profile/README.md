# System32 Entertainment

Software, games, hardware, and small-batch goods.

## Projects

### Garage64
A Minecraft OptiFine/CEM pack builder for custom car resource packs.

- Compose cars from bodies and swappable parts
- Real-time 3D preview
- Texture and UV editing
- Exports `.jem`, `.jpm`, and `.properties`

### Goods
Fingerboards, skateboard decks, RC drift builds and parts, occasional merch.

### Other
Apps and tools for creator workflows and game communities.

## Repositories

- `garage64` — Minecraft CEM/OptiFine pack builder
- `sys32ent-site` — web presence
- `commerce` — storefront and drops
- `minecraft-tools` — Minecraft utilities
- `infra` — deployment and internal tooling
